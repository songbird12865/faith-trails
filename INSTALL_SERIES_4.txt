FAITH-TRAILS SERIES 4 - WISDOM & FAITHFULNESS

This package adds five complete playable quests:
  16. Solomon
  17. The Ten Commandments
  18. Elijah
  19. Nehemiah
  20. Job

The application now contains 20 playable quests and 60 earnable badges.
Each Series 4 quest includes six changing story illustrations, an activity,
age-related Easy/Medium/Hard quizzes, a WEB memory verse, and a closing lesson.

SAFE LOCAL TEST
1. Extract this package into a separate folder.
2. Do not copy your live faith_trails.db into the folder until you have made a backup.
3. From the extracted folder, run:
       python -m unittest test_faith_trails.py -v
4. Generate the new narration files with your Series 4 voice configured:
       python generate_narration.py
5. Start the app:
       python app.py

PYTHONANYWHERE
1. Back up the live project and faith_trails.db first.
2. Upload the new and changed code and artwork files.
3. Keep ELEVENLABS_API_KEY in the PythonAnywhere environment; never place it in code.
4. Set ELEVENLABS_VOICE_ID_SERIES_4 to the voice chosen for this series.
5. Do not run schema.sql against the live database.
6. Reload the web app. The existing non-destructive migration will unlock Series 4
   without deleting profiles or previously earned badges.
